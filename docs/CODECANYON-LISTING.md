## Item title

FacilityFlow — Interactive Facility Map & Wayfinding CMS (React, Static + Node Backend)

## One-liner

Scan a QR code, get a beautiful interactive facility map. Zero-backend static
mode for instant deploys, or flip one switch for a full multi-user CMS with
roles, analytics and instant publishing.

## Feature bullets (sales page)

- 🗺️ Buttery-smooth mobile map: pinch-zoom SVG floor plans, tappable zones, bottom sheets
- 📱 QR wayfinding: per-zone "You are here" codes, printable poster & bulk sheets
- 🔀 Dual Mode: 100% static JSON deploy **or** Node + SQLite backend — switchable from settings, auto-fallback if the API is down
- 👥 Multi-user (Backend Mode): 4 roles, JWT + refresh tokens, bcrypt, activity log
- ✏️ Visual editors: polygon drawing on the floor plan, TipTap rich-text legal pages
- 🚨 Emergency mode, status badges, stairs/elevator floor jumps, favorites, search + tag filters
- 🌐 Multi-language (English + Sinhala included, structure ready for more)
- 📴 PWA: installable, fully offline after first visit
- 🔍 SEO-ready: meta/OG/Twitter tags, JSON-LD, sitemap.xml, robots.txt, clean URLs
- 🏷️ White-label switch, brand colors, logo upload — no code needed
- 📊 Analytics dashboard: most-viewed zones (device-local or server-side)
- 🐳 Docker Compose one-command start, PM2 config, deploy guides for 6+ hosts
- 📚 Buyer-friendly docs: installation, dual mode, roles, customization, FAQ

## Demo video script (60–90 s)

1. (0–10 s) Phone scans a printed QR → splash → map opens on "You are here".
2. (10–25 s) Pinch-zoom, tap Inventory → bottom sheet: safety notes, photo,
   Get Directions route animates.
3. (25–35 s) Tap stairs → jump to First Floor; toggle Sinhala; toggle dark mode.
4. (35–45 s) Hit the red emergency button → exits pulse.
5. (45–70 s) Desktop: admin draws a polygon, saves, hits **Publish now** →
   phone refreshes with the new zone.
6. (70–85 s) Flash the Users screen, Pages editor and Docker `up` terminal.
7. (85–90 s) Logo + "Static or full-stack. Your facility, mapped."
